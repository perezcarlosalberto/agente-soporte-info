Política de Privacidad

Agente-Soporte · Última actualización: 13 de octubre de 2026

Datos a los que accede

La app accede únicamente a la hoja de cálculo de Google Sheets del proyecto, donde se guardan las respuestas del formulario de quejas y sugerencias.

  • Lee el nombre y el comentario de cada respuesta.
  • Escribe la clasificación, el sentimiento y la marca de procesado.

Cómo usa los datos

El texto de cada comentario se envía a la API de Google Gemini únicamente para analizarlo (clasificarlo y detectar su sentimiento). Los resultados se guardan solo en la hoja de cálculo original.

La app se ejecuta automáticamente con GitHub Actions. Los registros de cada ejecución muestran el nombre del cliente y el resultado del análisis (clasificación y sentimiento); se guardan en el repositorio público del proyecto en GitHub, donde cualquier persona puede consultarlos, y se eliminan automáticamente a los 90 días.

Lo que no hace

  • No guarda los datos en otros servidores, salvo los registros de ejecución descritos arriba.
  • No vende ni comparte los datos con terceros, salvo el envío del comentario a Gemini para su análisis.
  • No usa los datos con fines publicitarios.
  • No accede a otros archivos de Google Drive.

Cómo revocar el acceso

Puedes quitarle a la app el acceso a tu cuenta de Google en cualquier momento desde myaccount.google.com/permissions.

Uso de datos de Google

El uso que Agente-Soporte hace de la información recibida de las APIs de Google, así como su transferencia a cualquier otra aplicación, se apega a la Política de Datos de Usuario de los Servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de uso limitado (Limited Use).
